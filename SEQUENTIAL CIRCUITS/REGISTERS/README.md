# VLSI Register Design
This repository contains Verilog/SystemVerilog implementations and learning examples for digital register designs.
It covers SISO, SIPO, PISO, and PIPO shift registers with their waveforms and truth tables.
The examples are intended for RTL design practice, simulation, and VLSI industry interview preparation.
All designs can be simulated using standard Verilog/SystemVerilog simulators.
