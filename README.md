# Verilog HDL – Digital Design Fundamentals

## 📌 About This Repository

This repository contains fundamental digital design implementations using **Verilog Hardware Description Language (HDL)**. It covers logic gates, combinational circuits, and sequential circuits developed using **Gate-Level, Dataflow, Structural, and Behavioral modeling techniques**.

Each project demonstrates practical digital design concepts and includes a Design Under Test (DUT), testbench, simulation verification, and waveform results where applicable.

The repository serves as a learning resource and technical portfolio for opportunities in **RTL Design, Digital Design, FPGA Development, and VLSI Engineering**.

## 📂 Repository Contents

- **Logic Gates:** AND, OR, NOT, NAND, NOR, XOR, and XNOR gates.
- **Combinational Circuits:** Adders, subtractors, multiplexers, demultiplexers, encoders, and decoders.
- **Sequential Circuits:** Latches, flip-flops, counters, and shift registers.
- **Modeling Techniques:** Gate-Level, Dataflow, Structural, and Behavioral modeling.
- **Testbenches:** Test environments for verifying design functionality.
- **Simulation Results:** Waveforms and verification outputs where available.

## 🛠️ Tools and Technologies

- **Language:** Verilog HDL
- **Simulation Tools:** QuestaSim / ModelSim, VCS
- **Waveform Analysis:** QuestaSim / ModelSim, Verdi
- **Online Practice:** EDA Playground

## 🧪 Project Structure

Each project may contain the following files:

```text
project_name/
├── design.v       # Design Under Test (DUT)
├── testbench.v    # Testbench for functional verification
├── waveform.png   # Simulation waveform, where applicable
└── README.md      # Project description and usage instructions
```

*The actual file structure may vary depending on the project.*

## 🚀 Objectives

- Build a strong foundation in digital logic design.
- Implement digital circuits using different Verilog modeling techniques.
- Develop testbenches to verify hardware functionality.
- Analyse simulation waveforms and identify design errors.
- Strengthen practical skills relevant to RTL design, FPGA development, and VLSI engineering.

## ▶️ Getting Started

1. Clone or download this repository.
2. Open the desired project in your preferred Verilog simulator.
3. Compile the design and its corresponding testbench.
4. Run the simulation.
5. Inspect the output and waveform to verify the design's functionality.
